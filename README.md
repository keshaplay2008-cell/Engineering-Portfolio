# **Описание проектов**

Здравствуйте\!

В этой папке собраны мои проекты разных лет.

### **📁 Структура папок:**

* **Исходники** — проекты и исходные коды с решениями.  
* **Исполняемые файлы net 10.0** — пересобранные проекты (в виде папок с исполняемыми файлами).  
* **Старые Исполняемые файлы** — архивные .exe программы. Сами по себе они простые, но демонстрируют мой ранний интерес к разработке (в названиях файлов указаны даты их создания).  
  *Важное примечание:* При запуске Windows может выдать предупреждение (SmartScreen) — это связано исключительно с отсутствием цифровой подписи (сертификата разработчика). Никакого вредоносного ПО внутри нет\!  
* **Исполняемый файл 2.5Д** — одиночный .exe файл. Это мой самостоятельно написанный с нуля графический движок (в стиле классического Wolfenstein 3D).  
* **Исполняемые Юнити** — две полноценные игры: Up (для ПК) и Hamsters Shoulder (для Android).

### **🎮 Рекомендации и управление:**

**📂 Исполняемые файлы 10.0**

* **Движок столкновений 1** \* *Управление:* Нажатие правой кнопки мыши (ПКМ) создает квадрат. Если зажать кнопку, протянуть мышь и отпустить, созданный квадрат получит начальную скорость.  
  * *Механика:* Размер квадратов генерируется случайно, от размера напрямую зависит масса объекта.  
* **Движок столкновений 2** \* *Управление:* Первые 3 клика задают вершины первого треугольника (желательно ставить их против часовой стрелки), следующие 3 клика — вершины второго. После 6 нажатий на экране появляются оба объекта.  
  * ЛКМ — притягивает первый треугольник, ПКМ — притягивает второй.  
  * *Совет:* Желательно придать обоим объектам ненулевую скорость до их первого столкновения.

**📂 Старые Исполняемые файлы**

Все программы здесь довольно простые, но особого внимания заслуживают две игры:

* **2d Platformer** \* *Управление:* A / D / Space.  
  * *Нюанс:* На тот момент я еще не умел обрабатывать одновременное зажатие нескольких клавиш, поэтому делать это не получится. Этот баг непреднамеренно создает дополнительную хардкорность.  
  * *Структура:* Игра состоит из 3 уровней. Первые два — платформенные, третий — босс-файт (у босса два вида атак). Чтобы победить, нужно выжить на протяжении 10 атак.  
* **Ogent** (ранний проект без финального дизайна)  
  * *Управление:* A / D. У игрока 5 жизней.  
  * *Нюанс:* Есть баг с "замерзанием" игры при зажатой клавише.  
  * *Цель:* Чтобы пройти уровень, нужно несколько раз пройти от одного края экрана до другого, постепенно поднимаясь вверх.

**📂 Исполняемый файл 2.5Д**

* **.exe (2.5D Engine)** \* *Управление:* W / A / S / D. Движение происходит относительно глобальных осей X и Y, а не в сторону взгляда камеры.  
  * *Нюанс:* Присутствует баг — если смотреть прямо на блок, взгляд блокируется. В более поздних версиях я это легко исправил, но сохранился только этот ранний билд.

**📂 Проекты на Unity**

Полные исходные коды и исполняемые файлы этих игр доступны на моем Google Диске по ссылке: [Google Drive](https://drive.google.com/drive/folders/1lQIgWOddYS5jmkPq0yHeXsHG8q8dNkdS?usp=sharing)*

* **Up (ПК)**  
  * *Геймплей:* При клике мышкой стрелка меняет направление своего движения. Цель — уворачиваться от блоков и добраться до финиша.  
* **Hamsters Shoulder (Android)**  
  * *Режимы:* «Кубок» (игра на рекорд) и «2 игрока» (старый, больше не поддерживаемый режим).  
  * *Геймплей:* При тапе по экрану хомяк на скейте меняет направление своего ускорения. Важно учитывать физическую инерцию: съеденные семечки увеличивают не только счет, но и общую скорость.  
  * *Особенность:* Для этой игры я написал специального бота, который проходит уровни «идеально». Его геймплей можно увидеть на главном экране в качестве фонового видео.
